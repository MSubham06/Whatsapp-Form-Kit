Things that break

  • Number format. Country code + number, digits only — 919876543210. A leading +, a leading 0, or a bare 10-digit number fails silently: WhatsApp opens an empty chat with no error at all. The readout catches this.
  • Popup blocking. Keep window.open inside the click handler. await anything before it and the browser blocks it as an unsolicited popup.
  • Button wording. "Send on WhatsApp", not "Submit". People who don't expect WhatsApp to open assume the site crashed.
  • Test on a real phone. Desktop opens WhatsApp Web or the desktop app, which is a different path from the mobile app. That's what the QR is for.
  • Keep the phone fallback. Not everyone has WhatsApp, and a failed send should still turn into a call.
  • Keep the honeypot. Invisible to people, catches most bots for free, and easy to delete by accident when tidying markup.
